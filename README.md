## DMIT 注册账号教程：手把手走一遍

DMIT 注册过程本身很简单，就几分钟的事，主要是新手容易在 SSH 密钥那里卡住（这个后面单独说）。

### 第一步：打开官网，进入注册页面

进官网后，右上角找到 **Sign Up**，点进去就是注册页面。页面右上角可以切换语言，有中文选项，不习惯英文的可以先切成中文再操作。

### 第二步：填写注册信息

注册需要填的内容：

1. **名字 / 姓氏**：填真实姓名（或者拼音）

2. **邮箱**：用你常用的邮箱，后续订单通知、密钥下载链接都发这里

3. **密码**：正常设置，记住就行

4. **手机号**：填 +86 开头的 11 位号码

5. **国家**：选 China 或对应地区

6. **地址**：随意填，对付款没有影响

填完点提交，邮箱会收到一封验证邮件，点击激活链接，账号就创建好了。

### 第三步：登录后台，选套餐

账号激活之后，进入后台，点击顶部菜单的 **Create → Server**，就开始选套餐了。

这一步是整个流程里最需要花时间的，因为套餐分机房、分线路，不同需求选不同的。下面专门说这一块。

## 套餐怎么选：产品线速览

DMIT 目前三个主要数据中心——洛杉矶（LAX）、香港（HKG）、东京（TYO）——每个机房里都有 Premium / Eyeball / Tier 1 三种路线。

### 三种产品线的本质区别

| 线路系列 | 对国内的优化 | 适合谁 |

|----------|------------|--------|

| **Premium（Pro）** | CN2 GIA 双向优化，三网全走精品线路 | 对国内访问速度有强需求；电信用户优先 |

| **Eyeball（EB）** | CMIN2 / CMI 回程，比 Tier 1 好但不如 Pro | 联通 / 移动用户；预算有限但不想走普通线路 |

| **Tier 1（T1）** | 国际线路，无国内方向专项优化 | 面向国际用户建站；用来做落地或中转 |

简单说：对国内访问要求越高，越应该选 Premium；预算有限选 Eyeball；只需要国际带宽选 Tier 1。

### 按机房区分

**洛杉矶（LAX）**：套餐最全，价格在三个机房里竞争力最强。Premium 系列（LAX.Pro）三网 CN2 GIA，月付 $9.99 起；Eyeball 系列（LAX.EB）走 CMIN2，月付 $9.9 起；Tier 1（LAX.T1）国际线路，最低年付 $36.9。还有一个 Premium Secure（LAX.sPro），加了 Cloudflare Magic Transit 的 DDoS 防护，适合建站防攻击。

## 购买流程：从选套餐到付款

选好套餐之后，流程如下：

7. **选择付款方式**：支付宝、微信、PayPal、信用卡都支持，选支付宝之后跳转到支付页面完成付款即可

## 关于 SSH 密钥登录：新手容易卡的地方

说实话，这是让很多人第一次购买 DMIT 之后一脸懵逼的环节。

DMIT 默认**不支持用密码登录 VPS**，只能用 SSH 密钥。这是更安全的做法，但对新手来说有点不习惯。

流程是这样的：

1. VPS 开通后，第一次进入后台，会弹出 SSH Key 的对话框

2. 点击 **Download private key**，下载密钥压缩包

3. 解压后，里面有 `id_rsa.pem`（适用于 OpenSSH / macOS / Linux）和 `id_rsa.ppk`（适用于 PuTTY）

4. 用 SSH 工具（XShell、PuTTY、MobaXterm 或者直接用系统终端）导入私钥后连接

关键点：**一定要在弹窗出现的时候下载密钥**，如果关掉了，可以在后台找到"SSH Key Management"重新下载或者上传自己的公钥。

macOS / Linux 用终端直接连：

bash

chmod 600 id_rsa.pem

ssh -i id_rsa.pem root@你的VPS的IP地址



Windows 用户推荐用 XShell 或者 MobaXterm，DMIT 官方知识库里有对应的图文教程。
